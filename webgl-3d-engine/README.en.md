# WebGL三维引擎

#### Description
本三维引擎是基于Three.js进行二次开发，可用于数字孪生系统的开发，支持加载gltf格式的三维模型，提供模型的基础操作包括对象选择、移动，缩放、旋转，相机的移动等功能。
